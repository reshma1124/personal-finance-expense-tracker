# 💰 Personal Finance & Expense Tracker

A personal finance management application built with Python and Streamlit. The application helps users track income, expenses, budgets, savings, and spending patterns across different months and years.

## 🚀 Features

- Add and manage daily expenses
- Track monthly income and spending budgets
- Categorize expenses such as rent, groceries, utilities, insurance, dining, travel, and shopping
- Track different payment methods
- Create recurring monthly expenses
- Edit and remove transactions
- View monthly income, spending, and savings
- Monitor remaining monthly budget
- Analyze spending by category
- View month-by-month financial summaries
- Visualize yearly spending trends
- Switch between different months and years
- Input validation for expense entries
- Local SQLite database for data storage

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- SQLite
